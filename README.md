# 📖 Overview

This project analyzes housing market trends using Tableau and presents the insights through an interactive Flask web application.

Users can explore:

- 📈 Housing Sale Prices
- 🏠 House Age
- 🔨 Renovation Impact
- 🛏 Bedrooms
- 🚿 Bathrooms
- 🏢 Floors
- 📊 Interactive Dashboard
- 📖 Storyboard

The dashboard helps buyers, sellers, and analysts understand housing market behavior using interactive visualizations.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Sharonkumar28/Housing-Market-Analysis.git
```

Go inside the project

```bash
cd Housing-Market-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
