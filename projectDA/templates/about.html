About the Project

Methodology, technology stack, and data dictionary specifications.

Data Preparation Pipeline

The project automates data intake, cleaning, validation, and feature engineering through an automated Python pipeline prior to visual analysis in Tableau. The raw dataset contains residential home sales in King County, Washington (Seattle area) between May 2014 and May 2015.

Executed ETL Tasks

  • Duplicate Removal: Identifies and filters out multiple entries using the unique home ID field (retaining the first occurrence).
  • Missing Value Resolution: Evaluates missing/null entries. Erroneous records are dropped, and remaining features are imputed using column medians or modes.
  • House Age: Calculated field computed as Sale Year - Year Built. Negative ranges are clipped to 0.
  • Renovation Status: Computed as 'Renovated' if the renovation year is greater than 0, otherwise labeled as 'Not Renovated'.
  • Years Since Renovation: Computed as Sale Year - Year Renovated for renovated properties, and default-linked to House Age for non-renovated ones.
  • Price per Square Foot: Formulated as Sale Price / Living Area Square Feet, rounded to 2 decimal places.

Technology Stack

Python 3.x Flask (Backend) Tableau Public Chart.js (Local Fallback) HTML5 / CSS3 JavaScript ES6

Instructions

1. Open housing_analytics.twb in Tableau Desktop.
2. If prompted, confirm the connection to the cleaned data file data/cleaned_housing_data.csv.
3. Create or customize worksheets and dashboard layouts.
4. Select Server > Publish Workbook to publish to Tableau Public.
5. Copy your published dashboard embed URL and paste it into the config.py file under TABLEAU_DASHBOARD_URL.
